## Question 1: Accessibility

What is accessibility and why does it matter? Name at least two ways that labels make our form inputs more accessible?

**Your Answer:**

Accessibility is to make your website useable even for those disabled, it matters because it doesn't just help them but makes the website more effective for anyone to use.

Labels allow for screen readers to announce what the input is for and also for those with mobility or accuracy issues, clicking the label text will also focus the input box.

## Question 2: The `name` vs `id` Attribute

`for`, `name` and `id` are attributes we put on form labels and inputs, but they serve different purposes. Explain what each attribute is used for.

**Your Answer:**

For is used to match the id for an input. for tells the label which input it's linked to.

Name is used to organize the data once the form is submitted to the server.

Id is the identifier of the input and allows you to target the specific element using css.

## Question 3: Input Types

**Your Answer:**

We use specific input types because they are easier for input validation and restriction compared to using js under the hood for input validation.
